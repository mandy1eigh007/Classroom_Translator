# Classroom Translator

Live translation tool for ANEW instructors. Speak English, student reads in their language.
Uses MyMemory free translation API — no account, no API key, no cost.

## Setup on Replit

### 1. Import the ZIP
- Go to replit.com, click + Create Repl
- Choose "Import from ZIP" and upload classroom-translator.zip

### 2. Run it
- Click the green Run button
- Replit installs Express and starts the server
- Open the web preview URL on any phone in Chrome

That's it. No secrets, no keys.

## How to use
1. Student picks their language from the dropdown
2. Instructor taps the mic button
3. Speak in English — words appear in the top box
4. Translation appears automatically every few seconds
5. Tap Stop when done, Clear to reset for next session

## Languages supported
Spanish, Dari, Somali, Vietnamese, Amharic, Arabic, Chinese (Simplified),
Tagalog, Swahili, French, Portuguese, Korean, Hindi, Punjabi, Russian, Ukrainian

## Notes
- Mic requires Chrome on Android or desktop
- MyMemory free tier: 1000 words/day per IP (plenty for classroom use)
- No data stored, no account needed
