Learner view

Follow the class

Learners can join as a guest or use an account. The room link usually already contains the class code.

Language tiles

Choose the language used for translations, buttons, class notes, and study tools.

Join as guest

Enter the live class without creating an account. Saved work stays on that device unless it is synced later.

Sign in with email

Uses a learner account so saved phrasebook items and study work can follow the learner across supported devices.

A- / A+

Makes the live translated class text smaller or larger.

Lang

Changes the translation language without leaving the live class.

Study

Opens class notes, the printable study sheet, saved phrasebook, instructor messaging, and voice settings.

Live message block

Shows the instructor's English statement and the translated statement. Tap an English word to open its trade-aware definition, example, audio, and save controls.

Hold / Catch up

Hold pauses new statements on screen while the learner reads. The badge counts waiting statements. Catch up releases them in order.

Listen mode

Turns automatic read-aloud on or off for incoming translations.

Replay

Reads the newest translated statement again.

Need help

Sends a short help alert to the instructor without interrupting the class. The instructor sees the language and current learner signal.

Got it

Confirms that the latest statement was understood.

Shared video or document

Appears only when the instructor shares media. Video captions and document text follow the selected learner language.

Study tools

Keep what matters

Generate notes

Builds a translated summary from the current class transcript. Copy, share, or listen when those controls appear.

Open study sheet

Creates a printable review sheet from the day's class language and vocabulary.

Phrasebook

Stores words saved from live definitions. Speak reads a saved term. Delete removes it. Sync connects local items to a signed-in learner account.

Message instructor

Learners write in their own language. The instructor receives the message in English and can send a direct reply.

Slow / Natural voice

Controls the speed and available voice style used for read-aloud.

Change language

Leaves the current live view and returns to the full language picker.

Instructor dashboard

Prepare the work

The dashboard holds long-term class records. The live console handles the room happening right now.

Dashboard

Shows today's class, session control, learner lobby, help alerts, recent materials, translation queue, and the last session summary.

Classes

Creates and manages class records, trade focus, schedule details, and assigned languages.

Students

Add Student creates one learner. Import Roster adds multiple names at once. The roster shows preferred language, enrolled classes, last activity, and live status during a session.

Materials

Stores class source material, connects it to a class and subject, and shows translation coverage by language.

Pre-translate

Prepares material in selected class languages before learners need it.

Live sessions

Starts a new room, shows the active room, and lists past sessions with duration, learner count, languages, and status.

Translations

Tracks source material, completed languages, missing languages, update time, and available actions.

Vocab bank

Stores trade terms with context, category, language, translation, and verification status. This is where the trade vocabulary library will grow.

Reports

Summarizes sessions, learners, languages used, and translated material.

Settings

Manages account information, default class, default session language, and notification preferences.

Live instructor console

Run the room

New class / End class

New class creates a fresh room code and transcript. End class closes the active room for learners.

Pause mic

Stops microphone transcription without ending the room. Resume when instruction continues.

Mode

Applies vocabulary context such as General, OSHA / Safety, Construction / Trades, Forklift / BFET, or Flagging so ambiguous words translate correctly.

Send

Publishes typed English to every learner when speaking is not practical.

Classroom

Shows connected learners grouped by language. Select a learner to send a direct message.

Share a video

Loads a YouTube link into learner screens. The transport bar controls play, pause, seek, and close for the shared class view.

Share a document

Uploads text or a clear page image. Previous and Next move the learner view through prepared pages; Clear removes it.

Live transcript

Shows the current English speech recognized from the instructor microphone.

Learner messages

Collects translated learner questions and direct-message replies.

Recently sent

Shows published class statements. Export transcript downloads a class record; Clear history starts the visible feed over.

Preview class notes

Shows the English version of the AI study notes learners can generate, including coverage information.

Share with learners

Copies or sends the room link by the available phone options. QR opens a scannable code for learners in the room.

Room rule: the teacher dashboard and live console use the same signed-in instructor session. Open the live console from the dashboard so the room is authorized automatically.

Dispatch

Connect the field

Dispatch code

Connects one dispatcher and field workers to the same temporary communication room. Generate creates a code when setting up a new room.

Dispatcher / Field worker

Selects the correct workspace. Workers also enter their name and language.

Dispatcher access

Confirms the dispatcher is authorized to send jobsite messages.

Copy link

Copies the connected dispatch room link so workers can open the same code directly.

Mic / Send

Captures or types the dispatcher's English message, then sends it in each worker's selected language.

Quick commands

Sends common field instructions such as Head to site, Stop and wait, Call me, Return to base, Hazard ahead, and Confirm receipt.

Worker replay

Reads the newest translated dispatch message again.

Got it / On my way / Need help

Sends a fast status response back to the dispatcher.

Leave dispatch

Disconnects the current screen from the dispatch room.

Dashboard

Instructors

Sessions

Organizations

Settings

Subscription

Troubleshooting

Check this first

No live translation

Confirm the learner opened the current room link, chose a language, and still shows a connected status. The instructor should confirm the microphone is not paused.

Microphone unavailable

Allow microphone access for the site, then reload the live console. Current Chrome, Edge, or Firefox works best for classroom testing.

Wrong language

Use Lang during class for a quick switch, or Change language in Study to return to the full picker.

Text is hard to read

Use A- or A+ in the learner header. The setting stays on that device.

Instructor access screen

Sign in through the teacher dashboard first, then open the live console from the same browser.

Room code fails

Ask for the newest link or code. Starting a new class creates a new room and makes older links inactive.

Translation needs correction

Record the English phrase, translated phrase, selected language, and trade mode. Trade vocabulary corrections belong in the Vocab Bank.

Testing note: report the page, control, device, language, and what happened. Do not include passwords or private learner information in a bug report.
