 User reported that pasting a YouTube link into the teacher's "Share a
video" card and clicking Load did nothing — no video opened for the

Root cause: server.js fetchCaptions awaits YoutubeTranscript.fetchTranscript
with no timeout. The youtube-transcript package can stall indefinitely
when YouTube changes its internal API or rate-limits the request,
which means /video/set never resolves, the Load button stays disabled,
and broadcastVideo() is never called.

timeout the catch in /video/set falls through with captionsError set,
videoState is still populated, and broadcastVideo() runs so the player
opens for the teacher and all students (just without translated
captions).
